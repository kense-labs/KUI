# 两处滑块读数抖动修复

2026-11-05，用户指出刻度滑块的体重读数和区间分布滑块的价格读数在移动时抖动。

## 公开源码核对

- [Ruler Slider TSX/CSS](https://uiarc.dev/r/ruler-slider.json)，SHA-256 `1d057df1f30b30bb309fcc5e7d9d177bb1be497485ec8914740f420ad66c5a06`。源码按步长和最小值固定小数位；采用tabular-nums，每列用隐藏的0占位，字符列在静止和滚动时保持相同结构，位数变化时才伸缩列宽。
- [Range Histogram Slider TSX/CSS](https://uiarc.dev/r/range-histogram-slider.json)，SHA-256 `16c4830c88cad4923467144c004997a4841edbb40ba2e76016bd6726c8391a33`。顶部区间直接渲染格式化文本，采用tabular-nums、baseline对齐和nowrap，没有逐字进出动画。

## 定位与修复

刻度滑块原实现把动画中的逐字flex布局切回静止时的整段文字，并用近似字宽混合计算各字符宽度；快速更新又从上一个目标重启动画。整数时移除小数部分也让单位来回移动。现使用同一套持续存在的等宽数字列和真实字形测宽，34px行框及占位基线在各状态保持不变。0.5步长保留1位小数（例如70.0），新目标沿当前滚动位置和速度接续；进位只伸缩新列。保留既有0.24s数字运动参数，采用共享Slide；不声称该弹簧曲线等同参考站CSS easing。

区间分布滑块去掉顶部读数多加的RollingValue动画，改为静态tabular数字，固定20px行高、禁止收缩和换行，靠右对齐。数值、柱形图、轨道及事件仍由原模型驱动。共享RollingValue的其他使用方未变动。
