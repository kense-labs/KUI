# Model and tool marks

KUI displays brand artwork beside the corresponding model or integration name. Demo data does not connect to those services.

- The Kense mark comes from the repository's light and dark brand artwork.
- Claude, OpenAI, Gemini, Mistral, DeepSeek, Meta, Qwen, xAI, GitHub and AWS use [Lobe Icons](https://github.com/lobehub/lobe-icons), MIT, from `@lobehub/icons-static-svg@1.97.0`.
- Linear, PostgreSQL, Google Meet, Zoom, Slack, Notion, Figma, Vercel, Stripe, Supabase, Raycast, Jira, Gmail, Google Drive, Retool, Intercom and Zendesk use CC0 artwork from `simple-icons@15.0.0`. Neutral marks use the foreground color for the current theme. [Simple Icons](https://github.com/simple-icons/simple-icons)

The artwork is embedded in `brand_mark.rs` so copy-source installs and WASM previews need no remote asset requests. Brand marks belong to their owners. They identify the adjacent name.
