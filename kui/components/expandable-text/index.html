键盘与操作

文本实际高度超过设定行数时才显示阅读全文。

适用

  • 展开截断的长文本并可重新收起。

安装

用法

控件 API 在桌面与 WASM 上相同；宿主启动见安装页。

API

ExpandableText

由外层布局提供宽度，调整宽度会重新测量文本。

属性 类型 默认 说明
new (text, lines: usize) → Self – 由外层布局提供宽度，调整宽度会重新测量文本。
event TextExpanded – 订阅控件实体事件。

动效

  • 根据溢出高度展开 500–600ms，收起 400–450ms，渐变遮罩和箭头同步切换。

给 AI 的说明

  • kui add expandable-text
